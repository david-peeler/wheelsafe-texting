# wheelsafe-texting

The public pages for WheelSafe's fall-alert texting program, published with GitHub Pages at <https://david-peeler.github.io/wheelsafe-texting/>.

Don't edit the three pages here. Their source is `docs/public/` in the WheelSafe iOS repository; `scripts/publish_public_pages.py` there copies them into a clone of this repo. Only `index.md`, `_config.yml` and this README are edited here.
